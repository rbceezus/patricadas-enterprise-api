# EMPREST.AI — API

API REST do sistema interno de empréstimo de equipamentos de TI (EMPREST.AI).
Repositório separado do frontend (patricadas-enterprise-web), conforme a
arquitetura de dois repositórios da ADR-001.

## Mapa dos documentos
- Negócio: `docs/PRD.md`
- Decisões técnicas: `docs/adr/` (ADR-001 é a stack)
- Regras para o agente: `AGENTS.md` e `rules/restrictions.md`
- Especificação visual do produto: `docs/layout.md`
- Material de aula (SDD / greenfield): `docs/aulas/`
